## Build and run

Build from Git Bash (MinGW 32-bit), then run the game from PowerShell or Windows Terminal.

```bash
make          # build
make run      # run the game
make test     # run the test scripts
make clean    # delete build output
```

> **Note:** run `make run` from PowerShell or Windows Terminal, not Git Bash. Git Bash's default terminal is not a real Windows console, so key input will not work there.
